# Stochastic simulations

Stochastic and Monte Carlo simulations in Python, written for the course *Stohastičke simulacije u klasičnoj i kvantnoj fizici* (Faculty of Science, University of Split). Code comments and reports are in Croatian.

| Projekt | Sadržaj |
|---|---|
| [ifs-fractal-tree](ifs-fractal-tree) | Fraktalno stablo pomoću sustava iteriranih funkcija (IFS) |
| [monte-carlo](monte-carlo) | Monte Carlo metode |
| [random-walk-diffusion](random-walk-diffusion) | Slučajni hod i difuzija |
| [sir-model-criticality](sir-model-criticality) | Kritično ponašanje stohastičkog SIR modela na rešetki, veza s perkolacijom i imunizacija (seminarski rad) |
